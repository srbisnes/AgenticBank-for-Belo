## 2025-05-18 - In-memory TTL caching for external financial price feeds in Route Handlers
**Learning:** External market rate APIs like `api.belo.app/public/price` take ~210ms per roundtrip with a ~24KB JSON payload. In Next.js Node.js runtime route handlers, relying solely on fetch options like `{ next: { revalidate: 30 } }` does not guarantee in-memory reuse across dynamic requests or fallback pathways. Combining a module-level in-memory cache with a 30s TTL and a pre-compiled `Set` lookup for pair filtering reduces endpoint response latency from ~210ms to under 1ms (>240x speedup) for frequent requests while preserving fresh quotes.
**Action:** When integrating third-party price feeds into Next.js App Router route handlers, always pair standard fetch revalidation with an explicit module-scoped in-memory TTL cache to eliminate redundant network roundtrips.
